Getting started

Jga7 Mod Tool 1.0 · Windows 10 or 11 · A Plague Tale: Innocence on Steam

1. Start

Unzip the folder anywhere (not inside the game folder), then double-click JgaModTool.exe. Nothing is installed on your PC, and nothing goes to the registry or Program Files.

The first page shows the last installed mod and has an Open mods folder button. If Steam updated or verified the game, the tool tells you at start.

2. Make a mod

Tick Model, Hair or Eyes, drop your files, then Build.

Model

Your Blender model replaces Amicia's whole body in every chapter: clothes, skin, head and hands. Only the game's eyes and lashes stay.

  • Two parts: Cloth (cloth shading) and Skin (skin shading), each with its own textures: Color, Normal, Roughness, Metallic.
  • Square images of 1024, 2048 or 4096 (4K); each part can have its own size.
  • Chapter groups (Chapter I, Chapter II, main chapters, final chapters) are all on by default and can be unticked.

Hair

Your own hairstyle with your own Color and Alpha images (or one RGBA image) and an optional Normal image. Used in all chapters.

Eyes

A new eye color from one image, painted on the game's iris image.

Build

The tool checks your files first and tells you exactly what to fix before it builds. The finished mod is a small folder and .zip with only your changes, saved in your user folder under "Amicia Mods".

Building with 4096 textures takes long: about 25 minutes per game file on a slower PC. About 4 GB of free disk space is needed while building.

3. Install and restore

Drop a mod folder or .zip, then Install. Your original game files are saved first and every file is checked before it is copied in. Restore puts the original files back at any time. One Amicia mod at a time.

If the game is inside Program Files, Windows asks for permission once.

4. Kits for Blender

The tool makes the kits from your own game files the first time (they are never shared):

  • 0 Optimized Kit: Jga7's optimized Blender file (Blender 5.0 or newer)
  • A clean slate with Amicia's skeleton and a weighted body
  • Amicia's original parts, for reference
  • Seamless textures: skin, cloth, leather, metal
  • A hair kit and a head kit

The tool's How to export your model page gives the exact glTF export settings.

If anything goes wrong

Press Restore in the tool, or let Steam check the game files: Library › the game › Properties › Installed Files › Verify integrity.
